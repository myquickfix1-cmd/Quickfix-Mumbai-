Start With the Basics

Before assuming a major fault, a few simple checks rule out common, easily-fixed causes:

  • Check the temperature setting hasn't been accidentally changed
  • Make sure the door is sealing fully — a worn gasket lets cold air escape constantly
  • Check that vents inside aren't blocked by overpacked food, restricting airflow
  • Listen for the compressor — if it's silent, that's a different fault path than if it's running but not cooling

Common Causes Behind No Cooling

Low Refrigerant (Gas Leak)

A slow leak reduces cooling gradually over time rather than stopping suddenly.

Compressor Failure

If the compressor doesn't start at all, this is often the cause — needs proper electrical testing.

Frost Buildup Blocking Airflow

A faulty defrost system can let ice build up on the evaporator coils, blocking cold air circulation.

Condenser Coils Dirty/Blocked

Dust buildup on coils (common in Mumbai's dusty urban air) reduces heat exchange efficiency.

Control Board Fault

The board can fail to properly cycle the cooling system even when other components are healthy.

Faulty Door Gasket

A worn or torn seal lets warm air in constantly, making the fridge work harder without keeping up.

Avoid this mistake: Assuming a gas refill will fix it without checking for a leak first — if there's an active leak, a refill alone will just repeat the problem within weeks.
