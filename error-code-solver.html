FAQs

Washing machine mein error code aaye toh kya karein?
Pehle code ka matlab dekho. Tap, filter ya load jaisi chhoti cheezein khud check kar sakte ho. Motor, heater ya board wale codes mein machine band karke technician bulao.
Kya har brand ke code ka matlab same hota hai?
Nahi. Kuch codes model ke hisaab se alag matlab de sakte hain, isliye jahan fark hota hai wahan page par likha gaya hai.
Error code ke baad service charge kitna hai?
Service charge 499 hai (visit aur diagnosis ke liye). Part aur labour ka cost check ke baad bataya jata hai.
