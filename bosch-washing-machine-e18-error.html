Quick answer: E18 on a Bosch washing machine means the machine tried to drain and couldn't complete it within its expected time — almost always a blocked filter, pump, or hose, not a control board failure.
⚠️ Safety first: Agar paani leak ho raha hai toh main switch off kar de — taaki short-circuit ya PCB board jalne se bache. Aur agar motor se dhuan/smell aaye toh machine bilkul use na kare.

What the E18 Code Actually Means

Bosch machines monitor how long draining takes. If water isn't cleared within the expected window, the machine stops the cycle and displays E18 as a protective measure — rather than risk overflowing or running the spin cycle with water still inside. The code is a symptom of a blocked drain path, not a diagnosis of what's blocked.

Common Causes Behind E18

Blocked Drain Filter

Coins, buttons, and lint collect here — the most common cause of an E18 code by far.

Kinked or Blocked Drain Hose

A bent hose, or a clog in the building's drain line itself, restricts outflow.

Drain Pump Blockage

A small object lodged in the pump impeller stops it pushing water through effectively.

Pump Motor Fault

Less common — the pump itself has failed and needs replacement.

Drain Hose Positioned Too High

If the hose end is raised above the recommended height, it can prevent proper drainage by gravity/pump pressure balance.

What a Proper Diagnosis Looks Like

  • Check and clear the drain filter first — resolves most E18 cases on its own
  • Inspect the drain hose route for kinks, and confirm correct height positioning
  • Check the pump impeller for a jammed object
  • Test the pump motor directly only once the above are ruled out
Avoid this mistake: Replacing the drain pump before checking the filter is a common unnecessary repair — filter cleaning resolves the large majority of E18 cases at no part cost.

Can You Check This Yourself First?

With the machine unplugged and a shallow tray ready, open the filter access panel (usually bottom-front) and check for trapped debris. Also confirm the drain hose isn't kinked behind the machine. These two checks resolve most E18 cases without needing a technician visit.

Is This Covered Under Warranty?

If your Bosch machine is still under company warranty, a pump fault is typically covered. Once warranty has expired, an independent repair with genuine parts and our own 3-month service warranty is usually faster than the manufacturer's service queue.

FAQs

E18 error khatam karne ke liye machine restart karna kaafi hai?
Restart se error clear ho sakta hai temporarily, lekin underlying blockage clear kiye bina wapas aayega — filter check karna zaroori hai.
Filter khud clean kar sakte hain?
Haan, machine unplug karke aur neeche tray rakh ke — residual water niklega isliye tray zaroor rakho.
Baar baar E18 aa raha hai filter clean karne ke baad bhi?
Iska matlab pump ya hose mein deeper blockage ho sakta hai, ya pump motor hi fault ho sakta hai — technician se check karwao.
Ye issue kitni der mein fix ho jata hai visit mein?
Filter cleaning ho toh 20-30 minute mein ho jata hai. Pump replace karna pade toh part availability pe depend karta hai.
