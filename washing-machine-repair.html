Washing Machine Repair Questions

💡 Quick Fix: Washing machine se ajeeb awaaz aa rahi hai, kya main khud check kar sakta hoon?
Haan bhai! Mechanic bulane se pehle 2 cheezein khud check karein:
1. Drum ke andar check karein, kahin koi coin, chabi ya kapde ka button toh nahi phasa hai?
2. Check karein ki machine ekdum level zameen par hai ya nahi (imbalance se bhi awaaz aati hai).

Tip: Agar awaaz phir bhi na ruke, toh ho sakta hai drum bearing ka issue ho. Aise mein zyada mat chalayein nahi toh motor kharab ho sakti hai. Aap turant niche diye button se humein WhatsApp karein, hum guide kar denge!
💡 Quick Fix: Machine chal rahi hai par paani saaf nahi ho raha/smell aa rahi hai?
Iske liye service ki zaroorat nahi hai, aap khud ghar par kar sakte hain! Machine ke niche ek chota 'Drain Filter' hota hai, use khol kar saaf karein—wahan saari gandagi jami hoti hai. Saath hi, mahine mein ek baar garam paani aur vinegar/scaling powder daal kar khali machine chalayein (Tub Clean cycle).

Agar filter saaf karne ke baad bhi drainage ka problem ho, toh pump block ho sakta hai. Uske liye aap humein call karke expert technician bula sakte hain.
Washing machine spin nahi kar raha, kya wajah hai?
Motor capacitor weak hona, drive belt loose ya damaged hona, door lock sensor fault, ya control board (PCB) ka signal na dena — sab possible causes hain. Technician on-spot diagnose karke sahi fix karega.
Front load machine ka drain pump issue kya hota hai?
Lint ya debris se pump block ho jata hai, ya pump bearing worn ho jata hai, ya pump motor hi fail ho jata hai. Front load machines mein ye common issue hai — same visit mein zyada tar fix ho jata hai.
Machine paani drain hi nahi kar rahi?
Drain filter block, drain hose mein kink, ya drain pump fault — exact cause diagnose karke hi part replace karte hain.
Door lock nahi khul raha ya beech mein cycle ruk jata hai?
Door interlock switch fail ho sakta hai ya sensor circuit mein fault ho sakta hai — dono test karke fix kar denge.
Machine se paani leak ho raha hai?
Door seal damaged, hose connection loose, ya tub mein crack ho sakta hai — exact cause pehle identify karte hain.

Zyada tar galat detergent quantity ya type ki wajah se hota hai — machine fault nahi hota, lekin agar sensor overflow trip kar raha hai toh check karwana sahi rahega.
Machine chalte-chalte electricity trip kar deti hai?
Ye serious ho sakta hai — earth leakage ya heating element fault ki wajah se. Turant machine band karo aur humein call karo, safety issue hai.
